# Clean Commerce Web

Admin, Seller, and Buyer panel SPA for the marketplace.

## Stack

- Vite + React 18 + TypeScript
- Tailwind CSS v4 + shadcn-style primitives (new-york)
- TanStack Router / Query / Table / Virtual
- React Hook Form + Zod

## Setup

```bash
cd apps/web
npm install
npm run dev
```

API requests to `/api/v1` are proxied to `http://localhost:3000` in development.
